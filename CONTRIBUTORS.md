# Contributing to v

## Human Review Requirement

All submitted code must be reviewed and understood by a human before submission. You are responsible for every line you submit, regardless of how it was written.

## Human Communication Requirement

All communication on this project — issues, pull requests, comments, and discussions — must be written by a human. Automated or AI-generated messages are not welcome.

## AI-Generated Content

If an issue summary or pull request description is suspected of being written by AI, it will be closed without review. The contributor will need to resubmit with communication and code that reflects genuine human engagement with the problem. I am not going to read a 1000 word thesus that was written by a machine.

This is not a ban on using AI tools during development. It is a requirement that a human understands, owns, and stands behind everything they submit.
